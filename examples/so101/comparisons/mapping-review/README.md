# Take 3 and take 5 in the reusable mapping workbench

> Historical artifact scope: this page describes the specific earlier export or replay retained here. Kamino’s broader prototype also demonstrated leader-recorded motion refined in simulation, exported and executed on the physical SO-101 follower arm, with iteration between simulation and hardware. See [the current robotics account](../../../../docs/ROBOTICS_DEMO.md). Precise calibration and contact-rich manipulation remain ongoing work.

- `captures.json`: generated by the offline capture packager from preserved
  Windows references. Both have 599 samples and matching calibration hashes.
- `baseline-review.json`: actual browser download from the mapping panel,
  bound to `../../../assemblies/so101-guided/api-workflow/reviewed-project.json`
  (repository path: `examples/assemblies/so101-guided/api-workflow/reviewed-project.json`).
  Every mapping remains unverified; gripper conversion is unset.
- `browser-take5.png`: browser evidence; CAD/template-assisted geometry and
  uncalibrated camera, not a physical accuracy test.

The downloaded angular values match the earlier take-3/take-5 diagnostic FK
reports within 1e-12 radians. Take 3's shoulder value remains outside the model
limit; take 5 is within arm-joint limits. Both normalized gripper readings remain
unconverted. The UI also exercised candidate offset editing (then restored zero),
reset, save and reload. No hardware connection or model change was made.

Use [the mapping guide](../../../../docs/MAPPING_REVIEW.md) to package further
captures. Open the same reviewed assembly/package and load the baseline review,
or open any assembly and load `captures.json` to start a new unverified mapping.

## Timestamped playback

`captures-with-observations.json` contains the same take-3/take-5 evidence plus all
599 timestamped readings per capture. Load it to use play/pause/reset/scrub. These
are stationary captures, so playback should show only their small recorded
variation; they do not establish a moving-arm replay or verified joint mapping.
The historical summary pack and baseline review remain unchanged.
