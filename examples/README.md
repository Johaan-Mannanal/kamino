# Example and evidence categories

| Location | Meaning |
| --- | --- |
| `simulation/apple-20w-charger-cleaned/` | Real photo-derived rigid asset and generated exports; scale/mass estimated, collision approximated |
| `simulation/synthetic-*`, `simulation/asset-export/`, `simulation/frontend-live-windows/` | Explicit synthetic fixtures and integration evidence; not photo reconstruction |
| `so101/` | Imported reference-robot checks and physical comparison preparation; not generated articulation |
| `so101/cad-review/` | Offline comparison with supplied CAD; not an application CAD importer |
| `assemblies/` | Generated articulated engineering fixtures; each states its input provenance |

Historical reports describe the version and scope tested at their recorded time.
Preserve them; use docs/PROJECT.md for current scope. A successful simulation load,
reset or drop does not certify measured dynamics or automatic reconstruction.
