A COMPLETE EXAMPLE / NO ACCESS CODE

From two parts to a moving assembly.

This synthetic hinged panel shows Kamino's assembly-to-simulation workflow. Inspect the component meshes and reviewed joint settings, then download a portable MuJoCo scene with its validation report. No server, account or provider request is needed to run it.

Download MuJoCo bundleFull reproduction guide

Both parts are generated boxes. Mass, friction and drive settings are assumptions. This example demonstrates assembly preparation and export; it is not a photo reconstruction or physical accuracy test.

Inspect the inputs and result

  • Component meshes: Post and panel, in millimetres.
  • Reviewed properties and hinge settings.
  • Retained motion and relocation report and ZIP checksum.
  • Correction history: an insufficient drive gain failed tracking; a corrected revision passed while preserving the earlier attempt.

Open the download

In an isolated Python environment, install MuJoCo 3.3.7. Extract the ZIP, change to its directory and open the scene:

python -m pip install mujoco==3.3.7
python -m mujoco.viewer --mjcf scene.xml

On macOS, use mjpython -m mujoco.viewer --mjcf scene.xml if MuJoCo requests its dedicated launcher.

To rerun Kamino's headless motion and relocation checks, follow the tested local setup, then run:

python -m photo2sim.assemblies validate scene.xml --report validation-new.json

Success prints "passed": true. It establishes the checks in that report under the saved assumptions, not measured physical fidelity.
