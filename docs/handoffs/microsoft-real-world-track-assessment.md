# Microsoft: eligibility clarification

Rechecked October 25, 2026 against the rendered
[official Hive prize cards](https://hive.hackberkeley.org/prizes) and
[event Devpost listing](https://cal-hacks-13-0.devpost.com/).

## What the published rules establish

Built for the Real World asks for a production-minded AI agent addressing an
important problem, with productivity among the example domains. Customer Impact
uses the same challenge. The criteria concern customer insight, demonstrable
usefulness, a credible production path, responsible design and a complete workflow.

The inspected cards do **not** specify Azure, a Microsoft SDK, a particular model
provider, autonomous tool execution or a supplemental submission form. They also
do not define “agent” precisely. This is an observation about the published cards,
not a guarantee about additional organizer instructions. No Microsoft runtime
integration should be added solely on an assumed Azure requirement.

## Kamino's fit and remaining uncertainty

Kamino is a deployed, human-reviewed AI workflow for robotics asset preparation:
Meshy reconstructs geometry; Gemini suggests properties; the user reviews inputs;
deterministic preparation produces a portable MuJoCo bundle. Persistence, correction,
prior-export preservation and hosted checks support its production-path story.

It is not currently an autonomous planner controlling a robot. Whether the
existing workflow meets this track's agent requirement remains **unconfirmed**.
The team has not received a sponsor ruling. No adoption or measured efficiency
improvement is claimed. [Release evidence](../RELEASE.md) describes software
verification separately from physical accuracy.
