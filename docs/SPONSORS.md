# Sponsor and regular award targets

These are planned targets, not claims that access, integration, or eligibility is complete. Check the current event requirements before submission.

## Sponsor tracks

| Track | Role in Photo2Sim | Qualifying work to complete |
| --- | --- | --- |
| Fetch.ai — primary cash target | An agent guides reconstruction, property confirmation, simulation checks, and export | Register on Agentverse, implement Agent Chat Protocol, and make the full primary workflow usable through ASI:One |
| Vultr | Actual backend hosting or processing jobs | Obtain access, run a meaningful workload, and document the infrastructure contribution |
| Gemini API | Image interpretation, labeled property suggestions, requests for missing measurements | Integrate the API into the workflow and show how outputs are checked and confirmed |

### Fetch submission checklist

- [ ] Register at least one agent on Agentverse and make it discoverable through ASI:One.
- [ ] Implement Agent Chat Protocol and meaningful tool execution.
- [ ] Demonstrate the complete primary workflow inside an ASI:One conversation.
- [ ] Publish a public repository with run/test instructions and required agent details/tags.
- [ ] Include the required demo video.
- [ ] Submit through Devpost and the CalHacks ASI:One submission agent.

Fetch's published prize amounts have differed from Devpost. Confirm payouts with the sponsor rather than advertising an unverified amount.

### Infrastructure and access

Vultr advertises MLH credits and GPU-backed infrastructure; specific allocation, availability, and terms must be confirmed. GPU access is not required for the local MuJoCo smoke test when reconstruction runs through an external API.

Meshy is the selected reconstruction provider, not one of our selected sponsor tracks. Meshy API access/credits are separate from sponsor benefits. Never assume another sponsor's credits cover Meshy usage.

## Regular awards

- Overall awards: a complete workflow with a clear robotics-lab use case and measured setup-time savings.
- Most Technically Advanced: geometry processing, collision representation, property provenance, and reproducible simulation validation.
- Most Creative Project: a compelling real-object-to-simulation experience.
