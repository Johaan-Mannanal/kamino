# Upload team Markdown here

This is the shared inbox for context, research, progress, questions, and handoffs.

On GitHub: open this folder → **Add file → Upload files** → choose your `.md` files → commit to your branch and open a PR. You can also use **Add file → Create new file** to write directly in the browser.

Name files `YYYY-MM-DD-name-topic.md`, for example `2026-10-23-yash-gripper-measurements.md`. Start with [_template.md](_template.md) if useful. Preserve the author and source when pasting an AI conversation; its suggestions are proposals until verified.

Do not upload credentials, private personal information, datasets, or checkpoint files. Link large assets and state where teammates can access them.
