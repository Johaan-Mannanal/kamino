## Historical development records

`handoffs/`, `team-notes/`, `decisions/` and `superpowers/` preserve development
coordination, decisions and earlier plans. Their pending statuses, branch instructions
and ownership assignments describe their recorded time; they are not the current
setup guide or release plan. Start with the pages above for current behavior.
Original test reports, failed attempts and input provenance remain intact.

[Sponsor pursuits](SPONSORS.md), [Figma evidence](FIGMA_EVIDENCE.md) and older
hackathon demo scripts are supporting history, not new contributor prerequisites.
