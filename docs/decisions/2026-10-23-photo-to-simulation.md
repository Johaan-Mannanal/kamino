# Pivot to Photo2Sim

Date: 2026-10-23

## Decision

The team chose photo-to-simulation software as the core hackathon project. The project and GitHub repository are named Photo2Sim / `photo2sim`. The Python scaffold uses `photo2sim` instead of `dummy`.

The goal is two real objects becoming editable MuJoCo assets with measured scale, documented physical assumptions, collision geometry, validation results, and portable exports.

## Replaces

The DUMMY assembly MVP, component ownership table, hour-by-hour schedule, and primary hardware-award strategy are superseded. The active plan is an ordered phase task list without person assignments or time allocations.

Existing camera work, recordings, and hardware environments remain useful references. Repository history and teammate branches retain that work. The local checkout folders may keep their existing names so machine-specific commands continue to resolve.

## Targets

Sponsor tracks: Fetch.ai, Vultr, Gemini API. Regular awards: Overall, Most Technically Advanced, Most Creative Project. Integrations and eligibility are goals, not completed claims.
