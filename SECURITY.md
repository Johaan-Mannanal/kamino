# Security reports

For a suspected vulnerability, use GitHub's private **Report a vulnerability**
option if available. Otherwise contact [Johaan](https://github.com/Johaan-Mannanal)
to arrange a private reporting channel before sharing exploit details or private
data. Do not post secrets, access codes, uploaded photos or private job artifacts
in a public issue. No response-time or supported-version guarantee is offered.

For ordinary bugs, use [GitHub issues](https://github.com/Johaan-Mannanal/kamino/issues)
and include a minimal synthetic reproduction, source revision, environment and
sanitized error. Avoid provider calls and hardware operation when reproducing an issue.
