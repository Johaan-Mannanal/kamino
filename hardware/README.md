# Hardware workspace — Yash

- `cad/`: editable source designs, dimensions, and units.
- `prints/`: STL/3MF exports with material, orientation, print settings, and revision notes.

Start with a peg/ring fit test, then print the fixed base, three interchangeable parts, pickup tray, and positioning jig. Dimensions in the project plan are starting assumptions, not validated measurements.

Check reach and gripping clearance before long prints. Record the design revision used for each trial. Avoid committing slicer caches or generated G-code; keep reproducible source/export files.
